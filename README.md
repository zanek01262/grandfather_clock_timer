# grandfather_clock_timer

ESP8266 chime monitor for a grandfather clock: an analog mic on A0 detects each
chime, logs it with an NTP-timestamped time and loudness, and shows it on a web
dashboard (live plot, tuning, chime log with Excel export) and the built-in OLED.

Firmware and docs are in [`GrandfatherClock/`](GrandfatherClock/) — start with
[`HANDOFF.md`](GrandfatherClock/HANDOFF.md).
